# Estatística para Pesquisadores · AIMS Camaleão

Slides em HTML da aula **Estatística para Pesquisadores** (60 min, público multidisciplinar), de Johsac Isbac Gomez Sanchez, no Grupo de Estudos Camaleão ([AIMS] Artificial Intelligence through Multimodal Signal Processing).

Baseado no roteiro `../roadmap_aula_estatistica_pesquisadores.md` (Parte I: blocos 0–3, ~17 min · Parte II: blocos 4–8, ~43 min).

## Como abrir

Abra `index.html` no navegador. O arquivo é autocontido: todos os gráficos são gerados em SVG, sem imagens nem bibliotecas externas.

- `→` / espaço: avançar (nas lâminas animadas, avança passo a passo) · `←`: voltar · `F`: tela cheia
- `↓` / `↑`: pula para a próxima/anterior lâmina sem passar pelos passos
- `index.html#N` abre direto na lâmina N
